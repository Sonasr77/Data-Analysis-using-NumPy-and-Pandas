# Data-Analysis-using-NumPy-and-Pandas
Data analysis project using NumPy and Pandas for array operations, data manipulation, and basic analysis.
NumPy:

- Created an array.
- Checked shape, data type, and number of elements.
- Performed slicing.
- Converted Celsius to Fahrenheit.
- Found maximum, minimum, and mean temperature.

Pandas:

- Created a Series.
- Learned indexing and slicing.
- Filtered values.
- Modified and removed values.
- Converted marks into CGPA.
